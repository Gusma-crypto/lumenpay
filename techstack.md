# Tech Stack - LumenPay Lite Level 1

## Main Stack

```txt
Next.js + React + TypeScript + Tailwind CSS + Stellar SDK + Freighter API
```

## Packages

* `next`
* `react`
* `react-dom`
* `typescript`
* `@stellar/stellar-sdk`
* `@stellar/freighter-api`
* `lucide-react`
* `tailwindcss`

## Stellar

* Network: Stellar Testnet
* Horizon: `https://horizon-testnet.stellar.org`
* Wallet: Freighter
* Asset for Level 1: native XLM

## Deployment

Recommended deployment target:

* Vercel

## Not Used in Level 1

* Soroban SDK
* Rust smart contracts
* Database
* Backend API
* USDC asset handling
